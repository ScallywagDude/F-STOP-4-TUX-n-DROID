## Engine

Since 1.2 the engine is the March 2019 CS:GO partner source (https://archive.org/details/csgo_partner).

The Android launcher (`launcher/`, `src/launcher/android/`) and the OpenGL ES renderer (`src/togles/`) are based on https://github.com/nillerusr/source-engine, which the 1.0 and 1.1 releases were built on. Its launcher code is GPL-3.0; see the notices in those files.
