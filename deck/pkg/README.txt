F-STOP for Linux and Steam Deck (x86_64)
=========================================

INSTALL
1. Extract F-STOP-GO-Linux-x86_64-1.2.tar.xz where you want to keep the game. It needs about 7 GB once unpacked.
   Move the F-STOP-GO folder to its final place before step 2.
2. Run F-STOP to play. On a Steam Deck, open the folder in Desktop Mode and double-click "Install F-STOP.sh"
   (choose Execute; Steam must be open), then return to Game Mode: F-STOP is in your library under Non-Steam.

The first map load takes longer while the graphics driver prepares its shaders.

IF SOMETHING IS WRONG
Will not start:   in Steam, F-STOP's Properties > Compatibility > force "Steam Linux Runtime 3.0 (sniper)".
                  The game was built against that runtime.
Other resolution: pass it after the name, for example  ./F-STOP -w 1920 -h 1080
Saves and settings live inside the F-STOP-GO folder. Keep fstop/SAVE and fstop/cfg if you reinstall.
