# STEAM ART

Steam artwork assets for F-STOP. The four supplied visual references are recreated as editable SVG graphics:

- `01-steam-library-header.svg` — 2000 × 646 header artwork
- `02-steam-library-capsule.svg` — 600 × 900 portrait capsule
- `03-steam-library-wide.svg` — 920 × 430 wide capsule
- `04-steam-logo.svg` — 1840 × 720 logo artwork

The SVGs can be opened in a browser or graphics editor and exported to PNG as needed.
